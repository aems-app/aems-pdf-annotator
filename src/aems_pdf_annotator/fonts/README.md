# DejaVu Sans

This font is a subset of DejaVu Sans Book 2.37. The upstream license is in
`DejaVu-LICENSE.txt`. The subset retains the characters supported by the face
in U+0020–052F, U+1D00–1FFF, U+2000–22FF, U+25A0–25FF, and U+FB00–FB06.
It was generated with FontTools 4.68.0 with all name IDs retained.

Upstream project and font releases: https://dejavu-fonts.github.io/
