# Annotator translation msgids

AEMS provides `window.i18n.t(msgid, params)`. The bundle resolves it when rendering;
without it, the English msgid is used and `%(name)s` parameters are interpolated.
Translations inserted into HTML are escaped, including double quotes in tooltips.
User comments, student names, supplied model names and stored placeholder sentinels
are data, and are not translated. Keyboard shortcut symbols remain unchanged.

Add Swedish entries for the exact msgids below (including case and punctuation).
This includes existing translated messages as well as strings routed through the
hook by this change. Tool and colour names are selected from fixed tables; history
messages are selected by action and direction. `Searching…` uses U+2026.

The toolbar in this repository contains Select, Text, Pen, Highlight and six colours.
Eraser/undo controls are not created by this source; host-owned markup must use the
host translator separately.
